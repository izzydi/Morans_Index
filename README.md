# Moran's I Spatial Autocorrelation Analysis

A spatial-statistics project exploring **Moran's I**, a widely used measure of spatial autocorrelation. The completed analysis is preserved as a rendered HTML report.

## Repository contents

- [`Morans_Index.html`](Morans_Index.html) — rendered analysis and visual output.

## Project focus

The project demonstrates how spatial structure can be assessed statistically rather than visually alone. Moran's I is used to investigate whether similar values tend to cluster geographically, disperse, or follow a pattern consistent with spatial randomness.

## Viewing the analysis

Download `Morans_Index.html` and open it in a browser. A GitHub-compatible HTML preview service can also be used to view the rendered document online.

## Reproducibility note

The repository currently contains the rendered output rather than the original source script/notebook. It is therefore maintained as a portfolio artifact of the completed spatial-statistics analysis.
