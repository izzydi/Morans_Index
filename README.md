# Moran's I Spatial Autocorrelation

A spatial-statistics project demonstrating Moran's I as a measure of spatial autocorrelation and presenting the analysis as a rendered HTML report.

## Repository contents

- [`morans_i_spatial_autocorrelation.html`](morans_i_spatial_autocorrelation.html) — rendered analysis and results.

## Project focus

The project explores whether geographically distributed values exhibit spatial clustering, dispersion or randomness using Moran's I and related spatial-analysis concepts.

## Viewing the project

Download `morans_i_spatial_autocorrelation.html` and open it in a modern browser. GitHub does not execute rendered HTML reports directly in the repository view.

## Reproducibility note

Only the rendered HTML report is currently stored in the repository; the original source script or notebook is not present. The repository therefore serves primarily as a portfolio artifact of the completed spatial-statistics analysis.
